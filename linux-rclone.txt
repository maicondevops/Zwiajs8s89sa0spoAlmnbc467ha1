# Guia Completo: Rclone com Google Drive no Ubuntu 24
Este documento serve como um manual de referência para a instalação, configuração e uso do Rclone para sincronizar dados do seu notebook Ubuntu 24 com 1 TB de armazenamento no Google Drive.

## 1. O que é o Rclone? (Conceito)
O **Rclone** é um programa de linha de comando (CLI), frequentemente descrito como "o canivete suíço para armazenamento em nuvem".

Seu principal objetivo é gerenciar arquivos em diversos provedores de armazenamento em nuvem (como Google Drive, Dropbox, S3, OneDrive, etc.). Ele não é um aplicativo com interface gráfica que roda em segundo plano; em vez disso, você o executa "sob demanda" no terminal para realizar tarefas específicas.

Ele funciona interagindo diretamente com a API (Interface de Programação de Aplicações) oficial do provedor de nuvem, o que o torna extremamente robusto e eficiente para transferir grandes volumes de dados (como 1 TB) e lidar com dezenas de milhares de arquivos.

## 2. Instalação e Configuração
Este passo a passo cobre a instalação no Ubuntu 24 e a configuração interativa para conectar sua conta Google.

### 2.1. Instalação
A instalação no Ubuntu 24 é direta através do gerenciador de pacotes `apt`:
```bash
sudo apt update
sudo apt install rclone
````

### 2.2. Configuração Interativa (Passo a Passo)

Este é o processo que fizemos para conectar o Rclone ao seu Google Drive.

1.  Inicie o assistente de configuração no terminal:
    ```bash
    rclone config
    ```
2.  **`n/s/q>`**: Digite `n` para criar um "New remote".
3.  **`name>`**: Dê um apelido local. (Ex: `GDrive`).
4.  **`Storage>`**: Escolha o tipo. Digite `22` ou `drive` para "Google Drive".
5.  **`client_id>`**: Pressione `Enter` (deixar em branco).
6.  **`client_secret>`**: Pressione `Enter` (deixar em branco).
7.  **`scope>`**: Digite `1` para "Full access".
8.  **`root_folder_id>`**: Pressione `Enter` (deixar em branco, para acessar a raiz do Drive).
9.  **`service_account_file>`**: Pressione `Enter` (deixar em branco).
10. **`Edit advanced config? (y/n)>`**: Digite `n` (ou pressione `Enter`).
11. **`Use auto config? (y/n)>`**: Digite `y` (ou pressione `Enter`).
12. **(Ação no Navegador)**: O Rclone abrirá seu navegador. Faça login na sua conta Google e clique em "Permitir" para autorizar o Rclone.
13. **(Volte ao Terminal)**
14. **`Configure this as a team drive? (y/n)>`**: Digite `n` (pois é sua conta pessoal).
15. **`OK? (y/e/d)>`**: Digite `y` para salvar a configuração.
16. **`n/s/q>`**: Digite `q` para sair do assistente.

## 3\. A Diferença Conceitual: `sync` vs. `copy`

Esta é a distinção mais importante para entender a segurança dos seus dados.

### `rclone copy` (Aditivo / Backup)

  * **Lógica:** "Acrescentar".
  * **O que faz:** Copia arquivos da **Origem** (seu notebook) para o **Destino** (Google Drive). Ele só transfere arquivos novos ou que foram modificados.
  * **O que NÃO faz:** O `copy` **nunca** apaga arquivos do Destino.
  * **Cenário:** Se você deletar um arquivo no seu notebook (`Origem`), o `copy` **não** o deletará no Google Drive (`Destino`). Isso é ideal para backups e arquivamento, pois protege contra deleção acidental.

### `rclone sync` (Espelhamento)

  * **Lógica:** "Espelhar".
  * **O que faz:** Faz o **Destino** (Google Drive) ficar *exatamente* idêntico à **Origem** (seu notebook).
  * **Ação Crítica:** Se um arquivo é deletado na **Origem**, o `sync` **irá deletá-lo** no **Destino** na próxima execução para manter o espelho.
  * **Cenário:** Útil se você quer que a nuvem seja apenas um reflexo exato do seu disco local, mas é perigoso se usado como backup único (se você for infectado por ransomware ou deletar algo por engano, o `sync` replicará essa deleção).

## 4\. Otimizando Seus Comandos de Backup (Filtros)

Seus comandos de exemplo mostram que você deseja excluir os mesmos tipos de arquivos (como `node_modules`, `.git`, etc.) de *todos* os seus backups. Repetir essas regras em cada comando é ineficiente.

A solução é criar um único **arquivo de filtro** e reutilizá-lo.

### 4.1. Crie o Arquivo de Filtros

Primeiro, crie um arquivo em sua pasta `home` para armazenar todas as regras de exclusão.

```bash
# Crie e abra o arquivo de regras de exclusão
nano /home/<usuario>/rclone_excludes.txt
```

Dentro deste arquivo, cole **exatamente** o seguinte conteúdo. Cada linha representa uma regra de exclusão:

```
# Excluir diretórios de código e cache
modules/**
__pycache__/**
bin/**
include/**
lib/**
lib64/**
node_modules/**
.git/**
```

Salve e feche o arquivo (Ctrl+O, Enter, Ctrl+X no `nano`).

### 4.2. Seus Comandos Otimizados e Mascarados

Agora, seus comandos de backup ficam muito mais limpos. Em vez de 10 flags `--exclude`, usamos apenas uma: `--exclude-from`.

*(Nota: Aspas são necessárias em caminhos que contêm espaços)*

  * **Comando 1: Documentos de Trabalho**

    ```bash
    rclone copy /home/<usuario>/Documentos/TRABALHO GDrive:BACKUP/DOCUMENTOS/TRABALHO \
    --progress \
    --exclude-from /home/<usuario>/rclone_excludes.txt
    ```

  * **Comando 2: Documentos Pessoais**

    ```bash
    rclone copy "/home/<usuario>/Documentos/DOCUMENTOS PESSOAIS" GDrive:BACKUP/DOCUMENTOS/PESSOAIS \
    --progress \
    --exclude-from /home/<usuario>/rclone_excludes.txt
    ```

  * **Comando 3: Máquinas Virtuais**

    ```bash
    rclone copy "/home/<usuario>/VirtualBox VMs" GDrive:BACKUP/VIRTUALBOX \
    --progress \
    --exclude-from /home/<usuario>/rclone_excludes.txt
    ```

  * **Comando 4: Arquivos Temporários**

    ```bash
    rclone copy /home/<usuario>/Documentos/Temp GDrive:BACKUP/TEMP \
    --progress \
    --exclude-from /home/<usuario>/rclone_excludes.txt
    ```

  * **Comando 5: Configurações de VPN**

    ```bash
    rclone copy /home/<usuario>/VPN GDrive:BACKUP/VPN \
    --progress \
    --exclude-from /home/<usuario>/rclone_excludes.txt
    ```

### 4.3. Exemplo de Comando Adicional (Verificação)

Antes de sincronizar, você pode querer verificar o que já existe na nuvem.

  * **Listar Diretórios no Destino**
    Este comando lista apenas os diretórios dentro da pasta `BACKUP` no seu Google Drive, permitindo que você veja a estrutura atual.
    ```bash
    rclone lsd GDrive:BACKUP
    ```
    *(Use `rclone ls GDrive:BACKUP` para listar todos os arquivos).*

## 5\. Como Revogar o Acesso

Existem duas maneiras de quebrar a conexão entre o Rclone e o Google Drive. A primeira é a mais segura.

### 5.1. Opção A: Revogar no Google Drive (Recomendado)

Isso torna o "token" de autorização que o Rclone salvou no seu PC inválido, bloqueando o acesso na fonte.

1.  Acesse sua conta Google: [myaccount.google.com](https://myaccount.google.com/)
2.  No menu à esquerda, clique em **Segurança**.
3.  Role para baixo até a seção "Suas conexões com apps e serviços de terceiros" (ou "Apps de terceiros com acesso à conta").
4.  Encontre **Rclone** na lista e clique nele.
5.  Clique em **Remover Acesso** (ou "Excluir todas as conexões que você tem com o Rclone") e confirme.

O Rclone no seu PC não conseguirá mais se conectar.

### 5.2. Opção B: Revogar no PC Local

Isso apenas apaga a configuração do Rclone no seu notebook. O Google ainda listará o Rclone como "autorizado" (embora ele não esteja sendo usado).

1.  Execute o assistente de configuração:
    ```bash
    rclone config
    ```
2.  **`n/s/q>`**: Digite `d` para "Delete remote".
3.  Selecione o "remote" que você criou (ex: `GDrive`).
4.  Confirme a exclusão digitando `y`.
5.  Digite `q` para sair.
